기술 문서

DATAVE Standard — 용어표준화 AI 에이전트

마지막 정리: 2026-09-17 · 코드와 함께 갱신되는 살아있는 문서입니다 — 어긋난 부분을 보면 그 자리에서 고쳐주세요.

이 문서는 CLAUDE.md(왜 이렇게 만들었는가)를 대체하지 않고, 지금 무엇이 있고 어떻게 맞물리는지를 코드베이스가 커져도 참조할 수 있는 형태로 정리한 레퍼런스입니다. 유지보수·디버깅·다음 기능 설계 시 여기서 먼저 구조를 확인하고, "왜 이런 선택을 했는지"가 필요하면 CLAUDE.md로 넘어가세요.

문서 두 개를 유지하는 이유 코드가 바뀌면 이 문서도 같이 고쳐야 하는 수고로움이 있지만, 그만큼 "코드가 실제로 이렇게 동작하나?"를 문서 두 개가 서로 검증하게 됩니다. 특히 MCP 로직(대화 상태머신, 도구 계약)이 자주 바뀌는 이 프로젝트에서는, 그 변경들이 실제로 어떤 순서로 어떤 버그를 잡으며 지금 형태에 이르렀는지를 변경 이력에 남겨두는 게 다음 디버깅 시간을 크게 줄여줍니다.

이 문서를 최신으로 유지하는 법

  • MCP 도구를 추가/변경/삭제했으면 → reference.html의 도구 표를 같이 고치세요.
  • 대화 상태머신(stage/전이)을 바꿨으면 → architecture.html의 상태머신 다이어그램을 같이 고치세요.
  • 실사용/QA 중 버그를 찾아 고쳤으면 → changelog.html에 한 항목 추가하세요. 커밋 메시지에 이미 "문제 → 원인 → 수정"을 적는 습관이 있으니(이 프로젝트 관례), 그 내용을 거의 그대로 옮기면 됩니다.
  • 새 테이블/컬럼을 추가했으면 → architecture.html의 데이터 모델 표를 같이 고치세요.
